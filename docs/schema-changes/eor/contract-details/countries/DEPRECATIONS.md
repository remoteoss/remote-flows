# Deprecated Contract Details Versions

Contract details schema versions that have been, or are about to be, retired. Pinning a deprecated version in `jsonSchemaVersionByCountry` stops working as intended: once a version has expired, requests pinned to it are served the latest schema, so the form can change under you. Move to a current version using the country guide.

## Upcoming deprecations

No versions are scheduled to expire.

## Expired versions
