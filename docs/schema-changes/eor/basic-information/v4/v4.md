# Basic Information v4

**Available in:** SDK 1.46.0

## Overview

Schema v4 is the **recommended** version from **2026-08-06**, you can use it for all countries.

At the current date, **2026-08-06**, the SDK will load by default v1, you only need to pass the correct version.

## Key Changes

- New fieldset called login email which determines how users can log in

## Visual Comparison

📄 **[View detailed comparison with screenshots →](./v4-changes.pdf)**

## Caveats

This schema affects all countries

## Migration

```tsx
// Before
<OnboardingFlow {...onboardingProps} />;

// After
<OnboardingFlow
  options={{
    jsonSchemaVersion: {
      employment_basic_information: 4,
    },
  }}
/>;
```
