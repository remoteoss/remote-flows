# Basic Information v5

## Overview

Schema v5 is the **recommended** version, you can use it for all countries.

The SDK loads v1 by default, you only need to pass the version you want.

## Key Changes

- `tax_servicing_countries` now accepts Global (`global-Global`), regions (`region-Europe`), subregions (`subregion-...`) and country names.
- The backend returns this shape only when the tax servicing by area feature is enabled for the company. Otherwise it returns the same shape as v4.

## Caveats

- This schema affects all countries.
- If you use a custom countries component for `tax_servicing_countries`, it must handle the option `$meta.type` (`global`, `region`, `subregion` or `country`). The SDK's default component already does.

## Migration

```tsx
// Before
<OnboardingFlow
  options={{
    jsonSchemaVersion: {
      employment_basic_information: 4,
    },
  }}
/>;

// After
<OnboardingFlow
  options={{
    jsonSchemaVersion: {
      employment_basic_information: 5,
    },
  }}
/>;
```
