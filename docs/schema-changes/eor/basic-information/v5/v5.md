# Basic Information v5

## Overview

Schema v5 is the **recommended** version from **2026-10-19**, you can use it for all countries.

At the current date, **2026-10-19**, the SDK will load by default v1, you only need to pass the correct version.

## Key Changes

- The `tax_servicing_countries` field now accepts region, subregion and "Global" values in addition to country names. Partners on the latest version can send grouped values such as `global-Global`, `region-Europe` or `subregion-Southern Europe`.

## Caveats

This schema affects all countries that ask for `tax_servicing_countries`.

Older versions only accept country names for that field. If you have a custom UI that offers regions, subregions or "Global", you must pin v5.

## Migration

```tsx
// Before
<OnboardingFlow {...onboardingProps} />;

// After
<OnboardingFlow
  options={{
    jsonSchemaVersion: {
      employment_basic_information: 5,
    },
  }}
/>;
```
