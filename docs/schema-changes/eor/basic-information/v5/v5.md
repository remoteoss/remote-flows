# Basic Information v5

## Overview

Schema v5 changes how `tax_servicing_countries` is accepted. It is available for all countries that ask for that field.

The SDK works differently from the Remote platform here: the default field still renders country names and keeps working as before. Build your own picker if you want to offer regions, subregions or "Global".

## Key Changes

- The `tax_servicing_countries` field now accepts region, subregion and "Global" values in addition to country names. Grouped values are sent as `global-Global`, `region-Europe` or `subregion-Southern Europe`.
- Only one area can be selected: "Global" replaces every other selection, a region replaces its own subregions and countries, and a subregion replaces its own countries.

## Caveats

- Older versions only accept country names for that field.

## Migration

```tsx
// Before
<OnboardingFlow {...onboardingProps} />;

// After
<OnboardingFlow
  options={{
    jsonSchemaVersion: {
      employment_basic_information: 5,
    },
  }}
/>;
```
